# Black, White & Gray Portfolio (React + Vite + Framer Motion)

    npm install
    npm run dev
    npm run build

Replace: contact info in `Footer.jsx` / `Contact.jsx`, social links in `Socials.jsx`, project images in
`Portfolio.jsx`, profile photo via the `src` prop of `<Avatar />` (`Hero.jsx`, `About.jsx`), and add `public/cv.pdf`.
Palette tokens are the CSS variables at the top of `src/styles/global.css`.
